## Tentang Proyek

**Sistem Rekrutmen Outsourcing PT MDA** adalah platform berbasis web yang dikembangkan untuk membantu proses rekrutmen tenaga kerja outsourcing secara lebih efektif, terstruktur, dan transparan. Sistem ini dibuat sebagai bagian dari **skripsi / tugas akhir** dengan menerapkan metode **Agile Development** dan metode **Simple Additive Weighting (SAW)** untuk mendukung proses seleksi kandidat.

📍 Proyek Skripsi / Tugas Akhir  
🏢 PT Mitra Daksa Anarawata (MDA)  
🏫 Universitas Jenderal Soedirman – Teknik Informatika  
📅 Tahun: 2025–2026  

## Fitur Utama

- **Landing Page**: Informasi perusahaan dan daftar lowongan pekerjaan
- **Autentikasi Multi Role**: Login dan hak akses untuk Admin, HRD, dan Pelamar
- **Manajemen Lowongan**: CRUD lowongan pekerjaan oleh HRD
- **Profil Pelamar**: Pengelolaan data diri, pendidikan, pengalaman, dan skill
- **Lamaran Kerja**: Pengajuan lamaran dan tracking status seleksi
- **Interview & Offering**: Penjadwalan interview dan pengiriman offering
- **Perankingan Kandidat**: Implementasi metode SAW untuk seleksi kandidat
- **Dashboard Admin**: Monitoring data pengguna dan aktivitas sistem
- **Generate CV PDF**: Pembuatan CV otomatis dalam format PDF

## Teknologi

- **Frontend**: HTML, CSS, JavaScript, Bootstrap, Blade
- **Backend**: Laravel 11 (PHP)
- **Database**: MySQL
- **Deployment**: Laravel Cloud & GitHub

## Pengembangan & Timeline

Metodologi: **Agile Development** dengan pendekatan iteratif dan adaptif terhadap kebutuhan pengguna.  

Tools & metode:
- **Figma** untuk perancangan UI/UX
- **Blackbox Testing** untuk pengujian fungsional
- **System Usability Scale (SUS)** untuk evaluasi usability
